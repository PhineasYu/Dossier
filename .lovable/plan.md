## Plan
1. Open the Lovable GitHub integration: Plus (+) menu → GitHub → Connect project.
2. Authorize the Lovable GitHub App on your GitHub account.
3. Pick the GitHub account / organization where the repo should live.
4. Create the repository (Lovable will name it after the project unless you change it).
5. Wait for the first sync to push the current code to GitHub.
6. Verify the repository URL and that two-way sync is active, so future edits in Lovable push to GitHub and vice versa.

## What you'll get
- A public or private GitHub repo with the full project code.
- Automatic two-way sync: changes here push to GitHub, and commits pushed to GitHub sync back here.
- A backup you can clone, branch, and deploy elsewhere if needed.
