# Dossier 作品集导出包

## 目标
为 Claude 整理作品集提供一份完整的项目资料包：一份从始至终的项目 Markdown 文档，加上关键功能和界面的真实截图。不修改应用本身。

## 交付内容（保存到 Files）

1. **dossier-portfolio-case-study.md**（英文，便于 Claude 直接使用）
   - 项目概览：一句话定位、要解决的问题、“一次输入，两种输出”
   - 背景：Accel AI Innovate Hackathon（KTH AI Society 主办）、时间限制、评审形式
   - 从始至终的时间线：PRD → 温暖笔记风格 → 语音整理 → 孩子时间线/档案 → 文件档案 → 每日两个问题 → 双向语音 check-in → 搜索拆分进 Timeline/Archive → Dossier+ 聊天 → Tech-white 设计系统 → Landing、Google 登录、QR 卡
   - 关键决策与取舍（事实性总结，不含内部思维链）、被砍掉的功能
   - 设计系统说明（色彩 token、孩子颜色、问题颜色、四色 AI 环）
   - 技术架构（前端、后端、AI、语音转写与语音对话）
   - 截图索引：每张截图对应的功能说明与图注
   - 给 Claude 的作品集写作提示词

2. **截图文件夹 dossier-screenshots/**（从正在运行的应用直接截取，桌面 + 手机尺寸）
   - Landing 页（Logo、插画、订阅方案、登录）
   - Home：今日 check-in 卡片与 AI 表情
   - 语音 check-in 全屏界面（动画环、问题 1/2）
   - Timeline：Luca（蓝）与 Lucy（紫）切换对比、问题来源标签
   - Timeline 搜索结果
   - Archive：过敏红色提醒、身高体重曲线、食物/兴趣/朋友
   - 文件夹式文档档案及展开视图
   - Capture：每日问题、连续天数、活动日历、文字整理入口
   - Dossier+：AI 聊天对话、Polar QR 卡、统计语句

3. **dossier-portfolio.zip**：将 Markdown 与全部截图打包，便于一次上传给 Claude。

## 说明
- 截图使用演示数据，逐张检查（无空白、无报错、无溢出）后再交付。
- 实时语音对话需要麦克风，截图将展示其界面状态，而非真实通话过程。
- 无法确认的事实（如最终名次、确切赞助商名单）会标注为待确认占位。
